# Privacy Guard

Локальное веб-приложение для работы с видео и списком исключений. Интерфейс: обычное боковое меню, таблицы, формы и сгруппированные настройки. Светлая, тёмная и системная темы; русский, казахский и английский языки.

## Запуск

Нужен Node.js 22.12+ или 24 LTS. Проверено на Windows с Node.js 24.

Из PowerShell:

```powershell
cd D:\Projects\SafetyMonitor\privacy-guard
npm.cmd ci
npm.cmd run dev
```

Откройте **http://127.0.0.1:4173**. На Windows можно запустить `start.cmd`: он установит зависимости при первом запуске и запустит приложение. Остановка — `Ctrl+C` в терминале.

Это отдельный проект в папке `privacy-guard`. Файл `main.py` в родительской папке запускает прежний Python Safety Monitor.

## Что работает

- **Белый список:** добавление людей с 1–5 фотографиями, добавление автомобилей с номером и страной, изменение записей, дополнительные фотографии, удаление, поиск и фильтр активных записей.
- **Хранение:** сервер сохраняет данные в `data/whitelist.json`, фотографии — в `data/photos/`. Данные остаются после перезапуска и доступны из другого браузера на этом компьютере.
- **Фотографии:** JPEG, PNG, WebP, до 10 МБ и 20 мегапикселей. Сервер проверяет содержимое, учитывает ориентацию, уменьшает размер до 1600 пикселей и сохраняет JPEG без EXIF.
- **Номера:** проверка, нормализация пробелов, дефисов и похожих кириллических букв, запрет дубликатов в пределах выбранной страны.
- **Видео:** открытие локального файла, выделение прямоугольных областей, отмена выделения, удаление областей, сохранение настоящего WebM с закрытыми пикселями. Исходный файл не загружается на сервер.
- **Камера:** выбор доступной веб-камеры, реальный поток, ручное скрытие областей и запись WebM без звука. При отключении или уходе со страницы поток освобождается.
- **Настройки:** оформление, язык и параметры категорий сохраняются локально в браузере.

Автоматическое распознавание лиц, OCR номеров и другие модели в исходном проекте отсутствуют. Фотографии и номера теперь действительно сохраняются, но автоматическое применение исключений к видео требует подключения этих моделей. Вручную выбранные области работают независимо от белого списка и настроек автоматических категорий. `matchWhitelistPlate()` готов для сопоставления номера, полученного от настоящего OCR; сравнение лиц не имитируется.

Экспорт идёт в реальном времени и занимает примерно длительность видео. При скрытии вкладки сохранение файла приостанавливается; после возвращения нажмите «Продолжить сохранение». Результат ограничен 512 МБ, входной файл — 2 ГБ. Поддержка форматов зависит от браузера; для записи рекомендуется Chrome или Edge. Области остаются на заданных местах, слежения за движущимися объектами нет.

## Production-запуск

Остановите dev-сервер перед сборкой.

```powershell
npm.cmd run build
npm.cmd start
```

Сервер слушает `127.0.0.1:4173`. Это локальный инструмент без аккаунтов; приложение проверяет Host и Origin запросов к белому списку. Публикация в интернете потребует отдельной авторизации и настройки доступа. Статическая генерация не используется: белому списку нужен Node.js сервер.

Для другой папки данных задайте `PRIVACY_GUARD_DATA_DIR` перед запуском. Запускайте один сервер для одной папки данных. Резервная копия — вся папка `data/` при остановленном приложении.

## Проверки

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

Тесты проверяют сохранение и восстановление списка, конкурирующие изменения, нормализацию номеров, обработку фотографий, откат при ошибке записи, ограничения загрузки и проверку сетевых запросов.

## Структура

```text
pages/                 Видео, камера, белый список, настройки
components/            Редактор областей, загрузка, диалог записи
composables/           Состояние интерфейса и переводы
shared/types/          Общие типы белого списка
server/api/whitelist/  CRUD и выдача фотографий
server/utils/          Хранилище, проверка данных и обработка изображений
tests/                 Проверки серверной логики
scripts/start.mjs      Локальный production-запуск
```
